# TikTok Hashtag Bundles — 3rd Eye Supply

Pre-built hashtag bundles for each product category. Use 4-7 hashtags per post; rotate within a bundle so the algorithm doesn't treat your account as repetitive.

## How TikTok hashtag discovery works (2026 reality)

- The algorithm uses hashtags + on-screen text + audio + visual classification to decide what audience to surface your video to.
- **Hashtag volume isn't a signal of quality** — using `#fyp` `#foryou` `#viral` on every post actively HURTS reach in 2026. The algorithm reads those as low-effort tagging.
- **Niche hashtags outperform broad ones.** `#witchtok` (huge) gets you lost in the feed; `#orgone` or `#palosanto` finds your actual buyers.
- **Branded hashtags** (`#3rdeyesupply`) help build a content trail and let you find your own posts.

## The hashtag rules

1. **4-7 tags per post.** Fewer = under-discovery; more = spammy signal.
2. **Mix niche + broad.** 2-3 niche tags (audience finds you), 1-2 mid tags (algorithm classifies you), 1 broad tag (max reach if it hits).
3. **Always include `#ad` or `#gifted` when commercially relevant** — this isn't a discovery tag, it's a legal disclosure. Counts toward the 4-7 max.
4. **Rotate within a bundle** — don't use the exact same 5 tags on every post.
5. **Avoid auto-banned tags.** TikTok shadow-suppresses certain spiritual/wellness tags (e.g., `#manifest` is suppressed; `#manifestation` is OK; `#witchcraft` shadow-bans on some accounts).

## Tags to AVOID

| Tag | Why |
|---|---|
| `#manifest` | Shadow-suppressed since 2024 — outcome-promise flag |
| `#manifestyourdreams` | Same |
| `#cure*` | Auto-fact-check on health claims |
| `#heal*` (literal) | Same — `#healing` is fine, `#heals` is flagged |
| `#magicspell` `#spellcasting` | Suppressed periodically; varies by region |
| `#fyp` `#foryoupage` `#viral` | 2026 algorithm reads as low-effort tagging |
| `#freelance` `#money` `#wealth` (with spiritual content) | Cross-niche tag stuffing flag |

## When in doubt

Search the hashtag in TikTok first. If you see:
- **Lots of generic content + bots in the top posts** → low signal, skip.
- **Engaged creators, real conversations** → use it.
- **A banner saying "this hashtag may be associated with..."** → never use it, even if it's relevant.
